📖 Recovery Guide (How to restore in case of attack or server down)

  1. Step 1: Download & Extract Archive: Download the latest .zip backup archive and extract it.
  2. Step 2: Restore Uploaded Files: Copy the extracted uploads/ folder into your new SIMTS project folder.
  3. Step 3: Restore Database:
    • PostgreSQL: Run psql -U simts_user -d simts -f simts_postgres.sql (or execute the database_export.sql script in pgAdmin/psql).
    • SQLite: Copy simts.db into the instance/ folder.
  4. Step 4: Launch Application: Run python app.py to resume normal operations with all data intact.
